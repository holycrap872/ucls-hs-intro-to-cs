## Lesson Plan

This lesson introduces students to functions in Python and gives them the
language to be able to identify, describe, and create their own functions.

### Actual Lesson

- Opening problem
    - `f(x) = x * 2`, `g(x, y) = x + y + 1`
        - `f(5)`
        - ...
- Review
    - Functions
- PEMDAS
    - Comes from beginning of algebra
    - Two options:
        - A few more characters
        - Torture school children for centuries
    - LISP: `(+ 2 3)`, Python: `2 + 3`
- Functions in Python
    - Math -> Python conversion
        - `double(x)` (from opening problem)
        - `greet(x, name)`
    - Vocabulary
        - Name of function
        - Input(s) to function
        - Creates function
        - Function call
        - Output of function
    - Type annotations
- Grok!
    - Pay particular attention to how `return` works
    - What does it mean when there's no `return`, vs `return`, vs `return x`?
